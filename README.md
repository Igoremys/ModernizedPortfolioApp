# Advanced Photo Portfolio App

Полноценное Android-приложение для создания фотопортфолио.

## Возможности
- Регистрация и авторизация
- Красивый Material Design интерфейс
- Добавление фотографий
- Просмотр галереи
- Детальная информация о фото
- Профиль пользователя
- Настройки приложения
- Архитектура PCMEF

## Экраны
1. Splash Screen
2. Login
3. Register
4. Gallery
5. Add Photo
6. Photo Details
7. Profile
8. Settings

## Технологии
- Kotlin
- Jetpack Compose
- Navigation Compose
- MVVM
- Room
- Retrofit
- Material 3
